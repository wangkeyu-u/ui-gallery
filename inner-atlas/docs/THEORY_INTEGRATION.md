# 荣格八维与其他理论如何融合

日期：2026-11-16。提示词与知识库`2026-11-16.3`。本轮是产品与解释流程改进，未完成心理测量学或临床验证。

## 阅读依据和实际范围

- [IAAP：《Psychological Types》卷6公开摘要](https://iaap.org/resources/academic-resources/collected-works-abstracts/volume-6-psychological-types/)：核对内外倾态度与感觉、直觉、思维、情感四功能组合，主要阅读类型与附录摘要；没有读取荣格全书，也不把历史精神病理说法用于个人报告。
- [McCrae／Costa（1989），Duke作者页面的研究摘要](https://scholars.duke.edu/publication/1458465)：摘要报告部分MBTI指标与大五相关，并未支持清楚二分类型。这里只核实该项研究摘要，不把它当作所有功能理论的系统综述；相关也不能允许从本项目大五换算八维。
- [自我决定理论官方概述](https://selfdeterminationtheory.org/theory/)：核对需要与社会处境、自主及内化的层次。已有来源台账保留该条；本次没有重复算成新增来源。
- 依恋、认知评价／情绪调节、协作概念化、目标与行为层次沿用前轮所读出版社节选和开发者资料，具体范围见[书籍阅读范围](DEPTH_METHOD.md)，不声称本轮重读整本书。

来源共46条、知识摘要35条，不等于46项独立研究，也不因为理论增多就更准确。

## 测量与解释分开

新增24道**原创**八维反思题，每项3题：Se关注当下线索、Si比较主观经验、Ne探索多种可能、Ni形成整体图景、Te用外部标准组织、Ti核对概念一致、Fe关注共享价值、Fi辨认个人价值。这是项目对日常情境的操作化，不是荣格原题、正式八维量表、MBTI或能力测试。

第三题反向为6−答案，三个答案全有才显示认同均值1–5，不补分、不按功能排名、不归一为占比。两个方向可以同时认同；不能据分数推出主导／辅助／阴影功能、固定栈、四字母类型或疾病。情感不是情绪化，内外倾态度不是社交多寡，直觉不是预知。

新用户默认开启，可在设置关闭。默认166题，含健康182题，全开202题／12章。旧版备份缺少jung设置时按未开启导入，不强行插题；可从“荣格与多理论”页补24题，保留原回答，重新综合。基础综合门槛继续只使用142道核心题；八维回答不能代替人格、关系或核心覆盖。

## 六个视角怎样协作

| 视角 | 实际用于询问 | 不能据此推什么 |
| --- | --- | --- |
| 荣格功能 | 自报关注信息与判断依据的偏好 | 能力、先天栈、类型、阴影或病理 |
| 大五与情境 | 通常倾向与具体行动的异同 | 每次必然行为或现实成就 |
| 依恋 | 指定对象中的敞开、依靠、担忧 | 对方动机、所有关系或童年原因 |
| 自我决定需要 | 本人描述的自主、胜任、联结 | 没有施测的需要分数、匮乏或心理疾病 |
| 认知评价与调节 | 本次事件—当时理解—目的—结果 | 潜意识、长期病因或其他事件的目的 |
| 目标与叙事 | 本人明确给出的目标、价值与经历 | 一生的故事、核心创伤或命运 |

AI选择实际有直接资料、能回应问题的2–3个视角（不足时更少）。完整八维须有一条荣格交叉解释，其他视角只在资料支持时选择。每张卡分开自述、解释、相符与不同、局限、替代解释和核实问题；仍融合进整体与关系理解，不把所有理论机械写一遍。不同理论解释同一份自报不是独立验证，也不投票确定“真性格”。

例如：对Ne相关描述较认同、常先给建议，可以提出“探索办法是否先于确认对方需求”的问题；不能直接推出共情差、不爱对方或隐藏恐惧。依恋和具体倾听经历有自己的解释层次，须允许它们不同。
