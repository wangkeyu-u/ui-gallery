# 免费分享给朋友（开发演示）

当前演示使用免费的hostc HTTPS临时通道，把同一台Node服务的前端和分析接口一起开放。朋友用手机浏览器打开链接即可做题；不需要GitHub账号、后端地址或API密钥。默认本地答题，主动确认发送后才调用DeepSeek。

这次选择来自用户“免费、别的设备也能用，开发方式也可以”的要求。没有使用Sites，也没有创建付费托管资源。

## 使用边界

- hostc通道免费、无需注册；它是临时开发分享，没有长期可用性保证。进程或工作环境停止后网址可能失效。参考[hostc官方说明](https://github.com/akazwz/hostc)。
- DeepSeek API调用仍按密钥所属账户计费，不能把免费通道说成免费AI。默认一个分析包含两次模型调用。
- 本次演示显式启用`PUBLIC_ANALYSIS=true`，朋友不需要填写分析口令。服务端每小时最多6次分析尝试、同时1次；这不是供应商侧硬性金额上限。默认配置仍为false。
- 密钥继续只在服务端，GitHub和浏览器中不包含它。演示通道会传输已授权的题目、背景与报告，其服务也有自己的处理规则；本次观察到通道注入Cloudflare性能统计，请求不属于网站答卷API。
- 永久GitHub Pages地址仍能做题和看本地报告；它本身不能运行分析后端。

## 长请求处理

两轮分析实测可能超过两分钟。浏览器请求携带`X-Analysis-Keepalive: 1`时，后端校验资料后开始JSON响应，每10秒发送合法JSON前导空白；最后写入完整报告。通道可以流式转发这些数据，避免因等待首字节或空闲而提前断开。这不是实时推理展示，也不返回内部思考。

响应开始后若上游失败，返回显式`code`／`message`错误对象；浏览器即使收到HTTP 200也会把该对象识别为失败。未启用该请求头时，接口保持原有HTTP状态码。取消或断开仍会中止上游请求，不展示半份报告。两轮总预算仍为360秒，浏览器等待375秒。

`tests/sharing.test.mjs`覆盖无需口令的演示模式、延迟供应商完成前收到JSON空白、最终可解析的12章报告、错误对象、施测覆盖与来源限制。真实手机尺寸的公网流程与虚拟人校验记录见[虚拟人对照](PERSONA_CHECK.md)。

## 复现

```bash
# 在自己的服务端私有.env中填密钥、随机访问口令，并显式设置PUBLIC_ANALYSIS=true
npm start
# 另一个终端；托管工具不属于网站运行时依赖
npx hostc@latest 4173
```

把通道给出的HTTPS origin加入服务端`ALLOWED_ORIGINS`后重启Node服务，通道继续保持运行。当前云环境需要让通道客户端遵循继承的HTTPS代理；该适配只改了临时工具副本，未写入项目或上传网络凭据。浏览器和手机实际访问以正常浏览器为准。
