# 综合分析如何形成判断

方法核对日期：2026-11-16。用途是成人自我探索。本项目的中文译文、原创题及AI综合解释没有完成心理测量学验证；本页说明实现方式和证据缺口。

## 对照了哪些专业做法

| 公开资料 | 借鉴的原则 | 项目采用方式与限制 |
| --- | --- | --- |
| [AERA／APA／NCME《测验标准》](https://www.testingstandards.net/uploads/7/6/6/4/76643089/standards_2014edition.pdf)，1.0／1.1、10.12／10.15／10.16／10.17 | 解释的用途、组合测验及计算机报告本身也需要效度证据；解释须结合其他资料及替代解释 | 不把拼接工具和AI生成当作新测验已有效；区分自述与推断，并保留未知 |
| [ITC翻译与改编指南](https://www.intestcom.org/files/guideline_test_adaptation_2ed.pdf) | 改编后的解释需要针对目标群体的证据 | 不移植原版常模、不生成百分位或未经验证的准确率 |
| [NICE NG222，1.2.6–1.2.7](https://www.nice.org.uk/guidance/ng222/chapter/recommendations) | 评估不能止于症状数量；还要了解历史、持续时间、变化及生活功能 | 增加可选的持续时间、生活影响和具体互动背景；这是自述资料组织，不是临床访谈 |
| [MMPI-3出版机构说明](https://www.upress.umn.edu/test-division/mmpi-3/)和[PAI出版机构说明](https://www.parinc.com/products/pai) | 专业工具有单独研发的作答效度量表、常模和解释体系 | 仅比较方法，未复制题目、效度量表或计分阈值；普通反向题不能据此鉴定说谎或装病 |
| [APA词典：巴纳姆效应](https://dictionary.apa.org/barnum-effect) | 觉得一段话贴切不能证明它能准确区分个体 | 主题必须给出具体依据、反例、真正不同的解释及区分它们的追问 |

《测验标准》读取了相关章节，未声称通读全书。MMPI-3／PAI只读取公开说明，未读取付费技术手册。NICE直接页面访问返回403，相关建议通过官方域名检索摘要核对；来源台账保留了访问范围。

## 从回答到报告

1. **核查可用资料。** 服务端重新计分，记录缺失、模块范围和已有质量提示。没有经验证的作答效度量表，因此不会把答案一致、极端或矛盾当作说谎证据。
2. **保留各类资料的身份。** 原版题的项目译文、原创探索、假设性情境选择和自由背景有不同限制。多份同源自报仍来自同一人；“不同领域”不是统计独立。
3. **加入具体背景。** 可选问题包括目标、近期处境、反例、持续时间和变化、生活影响、一次具体互动。未填写不会自动补齐；健康题只有另行授权才发送。自由背景按预览提交，可能自行包含健康信息。
4. **提出可核实解释。** 先区分通常倾向、特定关系和近期变化，再检查不同领域是否支持同一解释。分数描述本次回答；某次自述行为只支持对那一次经历的描述，不能证明一个人总是如此。
5. **寻找能改变结论的事实。** 同样分数可对应不同处境。追问应区分长期模式、近期压力、实际关系互动和题目理解等可能解释，而不是只问“你觉得准吗”。
6. **编辑并再次检查。** 默认两次DeepSeek调用。第二轮收到同一份已授权的逐题回答、汇总证据与背景，审查转述、反例、对象范围、时点、引用和过度推断。初稿JSON格式或完整12章草稿的协议／引用问题可以交给这次既定编辑修订；不会手工补造报告或增加第三次自动调用。最后仍须通过完整结构与引用检查；不通过不展示。

## 什么证据还缺少

严谨性改进不能替代目标用户样本上的研究。下一步验证需要预先定义用途与主要结局、访谈和译文核查、合适规模与构成的样本、重测、结构分析、与合适外部标准的比较以及独立评阅。需要专门评估“AI解释有没有新增错误”；不能仅靠内部一致性、用户认同率或模型自我评分宣布有效。

本次真实API检查使用少量虚构答卷，只能发现实现失败、明显不合资料的解释和处境敏感性问题。它不能计算临床准确率、诊断敏感度／特异度或人格判断正确率。真实调用记录和发现见[验证记录](QA.md)。
