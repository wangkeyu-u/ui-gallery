# 验证范围

## 当前功能检查

`npm test` 检查本地画廊的卡片数量、图片加载、筛选、选择、localStorage、复制和控制台错误。`npm run test:copy` 检查单卡复制入口。这些检查不测量第三方网站或 AI 重建的动画质量。

## 历史复现记录

旧 README 报告 204 项进入评估、194 项标为复现通过、其中 191 项标为动画还原。`preview-data.json` 保留原有状态、失败记录、备注和提示词；本次清理没有重新判定这些状态。194/204 约为 95.1%，旧文档括号中的 100% 是错误表述。

完整逐站 `repro/` 原始输入、生成页面、迭代截图、独立评分标准和验收记录没有入库。删除的一次性批次脚本还包含硬编码的 passed 状态。因此历史字段不能证明所有条目都完成了可复核的逐帧视觉验收。页面徽章标明“历史”，仅展示已有数据。

[早期复现报告](../reports/repro-report.html)保留其原始结果。要发布新的质量结论，需要另外保存输入版本、生成页面、对比材料、评分方法和失败案例。
